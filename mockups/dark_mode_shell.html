Dark mode

The real Week and Game pages with a dark theme. The pages follow the phone's light or dark setting until someone uses the new switch in the bottom-left corner. Flip the switch in any phone and all three change together.

Phone setting

Following the phone

With no choice saved, the pages match the phone's own setting and change when it changes. Using the switch saves a choice on that device. Switching back to whatever the phone is set to clears the choice, so the page goes back to following the phone.

Games opened from the week list

A game opened from the week list lives in a sealed-off part of the page that outside styles can't reach. Colors can still pass into it, though. So every color becomes a named theme value set once at the top of the page, and the game's styles read those values. Try it in the Week phone: open PHI @ CHI, then flip the switch.
