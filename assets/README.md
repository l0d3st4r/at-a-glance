# assets

Static files the build copies into `site/` as-is (see `render_html.py`).

The site's icons are Jason's field-and-eye logo (`logo.py`, picked 2026-10-08 in the At A Glance Logo
artifact):

- `favicon-32.png` — browser-tab icon for browsers that don't use `favicon.svg`: the logo in the site's ink (#161510), transparent, at 92% of the square's width
- `favicon-dark-32.png` — the same in the site's paper (#F3F3EE), for dark browser tabs (its `<link>` carries a dark-mode media query)
- `apple-touch-icon.png` — 180×180 iPhone/iPad home-screen and Safari favorites icon, the site's default: the logo in clear glass on the site's ink, at 92% of the icon's width
- `apple-touch-icon-light.png` — the same in smoked glass on the site's paper, for light mode (its `<link>` carries a light-mode media query)

`site/favicon.svg` is generated by the build from `logo.favicon_svg()` and switches between ink and paper
by itself with the browser's theme. The PNGs are committed because the build has no SVG rasterizer: if
the logo changes, re-render them from `logo.favicon_png_svg()` (32×32, `dark=False` / `True`) and
`logo.home_icon_svg()` (180×180, `dark=True` / `False`). The current set was rendered with resvg
(`pip install resvg-py`, then `resvg_py.svg_to_bytes(svg_string=..., width=..., height=...)`); drawing
the SVG onto a canvas in a browser gives the same result.
